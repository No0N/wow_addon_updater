# ElvUI Updater

Приложение для обновления ElvUI и ClassCodex. ElvUI проверяется через Tukui, ClassCodex — через официальный production-канал U.GG с проверкой манифеста и SHA-256 каждого файла. Пути и чекбоксы сохраняются между запусками.

Программа проверяет новые версии через GitHub Releases. Загруженный EXE принимается только после проверки размера и SHA-256, предоставленного GitHub.

## Запуск из исходников

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Сборка в .exe

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Собрать exe:
   ```bash
   pyinstaller build.spec
   ```

3. Готовый файл: `dist/ElvUI_Updater.exe`. Конфиг сохраняется в папке рядом с exe (`elvui_updater_config.json`).

## Выпуск новой версии

1. Изменить `APP_VERSION` в `updater.py`.
2. Зафиксировать изменения и отправить тег с такой же версией, например `v1.1.0`.
3. GitHub Actions автоматически соберёт EXE и добавит его в новый Release.

## Использование

- **Версия на сайте** — кнопка «Проверить версию» запрашивает [API Tukui](https://api.tukui.org/v1/addons) (версия и дата обновления).
- Укажите папки версий игры: `_retail_` для WoW актуал и соответствующую папку WoW Classic.
- Отдельными флажками выберите, какие аддоны обновлять. ClassCodex использует общую папку Retail.
- «Скачать и обновить» загружает только те выбранные аддоны, чьи локальные версии отличаются от версий на сайтах.
- Для ClassCodex локальные файлы сверяются с SHA-256 из манифеста U.GG; скачиваются только отсутствующие или изменившиеся файлы.
